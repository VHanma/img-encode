# JelliForge

A multi-photo elastic animation editor for Android.

## What is different
- Load and animate up to 12 photos in one live grid.
- Edit one tile or enable Link All to mirror the same deformation across every photo.
- Five motion engines: Wobble, Pulse, Twist, Wave, and Elastic.
- Smart Motion seeds deformation anchors from high-contrast regions in each image.
- Phone tilt adds live motion.
- Save a still PNG, export the whole grid as an animated GIF, or batch-export one GIF per loaded photo.
- Offline editing, no account, no cloud processing.

## Controls
1. Tap **+ Photos** and multi-select images.
2. Drag inside a photo to create an elastic motion anchor.
3. Tap a tile to select it.
4. Toggle **Link All** to apply edits to all loaded photos at once.
5. Cycle the effect engine, seed Smart Motion, or reset.
6. Export to `Pictures/JelliForge`.

Package: `com.vhanma.jelliforge`
